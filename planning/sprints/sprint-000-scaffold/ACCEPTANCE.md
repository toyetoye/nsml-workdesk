# Sprint 000 Acceptance Criteria

Sprint 000 is complete when:

- app runs locally;
- dashboard visible at / or /dashboard;
- sidebar/navigation visible;
- all five workspaces visible;
- three vessel pages render separately;
- Projects page renders;
- Other page renders;
- Import placeholder renders;
- Cases placeholder renders;
- Drafts placeholder renders;
- Writing Style placeholder renders;
- mock status cards render;
- no Outlook integration exists;
- no email sending exists;
- no AI workflow exists;
- no database dependency is required.
