# Sprint 000 Requirements

## Goal

Create a clean running app shell for NSML WorkDesk.

## Requirements

1. The app must run locally.
2. Dashboard must be the landing page.
3. Navigation must include:
   - Dashboard
   - LNG PORTHARCOURT II
   - LPG ALFRED TEMILE
   - LPG ALFRED TEMILE 10
   - Projects
   - Other
   - Import
   - Cases
   - Drafts
   - Writing Style
4. Dashboard must show mock status cards:
   - Urgent
   - Pending My Reply
   - Waiting on Others
   - Decision Required
   - Drafts Ready
   - Needs Evidence
5. Vessel pages must render separately.
6. Projects and Other pages must render.
7. Import, Cases, Drafts, and Writing Style pages may be placeholders.
8. No database required.
9. No AI required.
10. No Outlook connection.
11. No automatic email sending.
12. No multi-user roles.
