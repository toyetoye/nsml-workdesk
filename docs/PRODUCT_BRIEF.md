# Product Brief

## Name

NSML WorkDesk

## User

Single user: Toye Omolade.

## Problem

NSML vessel and project work is spread across emails, attachments, screenshots, EMLs, vendor quotes, reports, and informal notes. Connecting Outlook directly to AI is not desired, but the user still needs a way to organise, triage, search, draft responses, and preserve evidence.

## Product

A private deployed web platform that accepts manually imported work material and converts it into structured cases, evidence, actions, decisions, alerts, and reviewed draft responses.

## Workspaces

1. LNG PORTHARCOURT II
2. LPG ALFRED TEMILE
3. LPG ALFRED TEMILE 10
4. Projects
5. Other / General Issues

## Dashboard

The dashboard is the command centre and landing page.

It must highlight:

- urgent items;
- pending my reply;
- waiting on others;
- decision required;
- drafts ready;
- drafts failed red-team;
- needs evidence;
- open cases by vessel;
- recent imports.

## v1 excludes

- Outlook connection;
- automatic email sending;
- multi-user collaboration;
- uncontrolled AI;
- direct external communications.
